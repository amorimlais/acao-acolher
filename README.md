# Ação Acolher

Ação Acolher é uma plataforma web desenvolvida para apoiar e divulgar iniciativas sociais, facilitando o acesso a informações sobre campanhas, doações e ações comunitárias.

## Sobre o Projeto

O projeto tem como objetivo fortalecer a comunicação entre a instituição, voluntários, parceiros e doadores, promovendo maior engajamento e transparência nas ações realizadas.

## Tecnologias Utilizadas

- React
- Vite
- JavaScript
- HTML5
- CSS3
- Git
- GitHub
- Netlify

## Funcionalidades

- Apresentação institucional
- Divulgação de campanhas e projetos
- Informações para doações
- Canal de contato
- Interface responsiva

## Execução Local

```bash
git clone https://github.com/amorimlais/acao-acolher.git
cd acao-acolher
npm install
npm run dev
```
